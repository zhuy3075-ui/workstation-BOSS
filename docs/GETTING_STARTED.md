# BOSS 工作台：下载与第一次使用

[返回软件介绍与完整使用指南](../README.md) · [填写自己的资料、AI 与备份](CONFIGURATION.md)

BOSS 工作台 v2.0.0 是给公司老板、个体工商户和小团队使用的单文件经营工具。基础管理功能离线可用；AI 拆解、分析和联网搜索需要另行配置相应接口。

## 获取软件

### 方式一：下载 ZIP

1. 打开 [workstation-BOSS 仓库](https://github.com/cyberdaddyleo/workstation-BOSS)。
2. 点击绿色 **Code → Download ZIP**。
3. 将压缩包完整解压到准备长期使用的文件夹。
4. 用电脑上的 Chrome 或 Edge 打开 `index.html`，双击或拖进浏览器均可。

GitHub 网页中的代码预览不是应用页面，需要下载后在本地打开。软件不需要注册工作台账户，不需要安装依赖或运行服务器。`ai-proxy.js` 只是遇到 AI 跨域问题时的可选工具。

### 方式二：Git 克隆

电脑已安装 Git 时，在准备存放软件的目录运行：

```bash
git clone --branch main https://github.com/cyberdaddyleo/workstation-BOSS.git
cd workstation-BOSS
```

然后打开 `index.html`。不需要运行 `npm install`、`npm run dev` 或构建命令。

## 第一次打开

欢迎页先选择内置的男老板 / 女老板形象，填写「怎么称呼你」和「职位」，再选择一种起步方式：

| 选择 | 会得到什么 |
|---|---|
| **先看看示例公司** | 「云栈科技」示例数据，8 个部门、39 名员工，以及目标、任务、客户和经营记录 |
| **直接用我的公司** | 填「公司 / 店铺名称」、行业，选部门模板后从空白业务数据开始 |

部门模板有 **科技公司、一般公司、个体户 / 门店、工作室 / 小团队**。模板只是起点，之后可以修改部门和人员。

点击「**开启工作台**」进入办公室。正在体验示例公司时，办公室顶部有「**开始录入我的公司**」；填写资料后点「**清空并开始**」即可换成自己的业务。这个操作会清除示例业务数据，保留老板形象和 AI 设置；已有自己录入的数据时先备份。

## 按这个顺序开始使用

1. **改成自己的资料。** 在「设置 → 老板形象」改称呼、职位和形象；在「设置 → 公司信息」填公司 / 店铺全称、简称、类型、行业、城市等。设置修改后自动保存。
2. **建好组织与名单。** 在「设置 → 部门 · 产品 · 渠道」管理部门、产品和获客渠道；进入「团队」添加员工，或从 Excel 复制花名册批量导入。
3. **先走一遍任务流程。** 在「目标拆解」写一个实际目标，先用「按模板拆」，审核负责人、执行人和截止日期后确认派发；到「任务派发」更新状态和进度。
4. **补齐业务记录。** 在「客户商机」录客户和跟进，在「经营数据」录合同、回款、成本、目标与预算。
5. **按需启用 AI。** 在「设置 → AI 接口」填自己的接口并测试；未配置时，也可用「复制提示词」把内容交给网页版 AI，再按界面要求粘贴结果。
6. **导出第一份备份。** 在「设置 → 数据与备份」点「导出备份」，将 JSON 私密保存。备份包含业务数据和已填写的 API Key，不要放进公开仓库。

完整功能与截图见 [README 使用指南](../README.md#使用指南)。具体字段和 AI 配置见 [配置指南](CONFIGURATION.md)。

## 保存、迁移与更新

- 日常数据保存在当前浏览器的 `localStorage`，不会自动同步到其他浏览器或电脑。使用正常浏览模式，并尽量保持相同的文件位置和打开方式。
- 清理浏览器、换电脑、移动文件或更新软件前，先从「设置 → 数据与备份」导出备份。
- 在另一台电脑上下载软件，再用「从备份恢复」导入。恢复会覆盖该浏览器当前的工作台数据。
- 已通过 Git 克隆且没有本地源码修改时，可在备份后用 `git pull --ff-only` 获取更新，再重新打开 `index.html`。若已有源码修改，先处理自己的修改再更新。
